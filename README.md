# hallucination-sensitive-qa-datasets

This repository contains structured factual QA datasets designed for evaluating hallucination behavior in large language models.

Included Domains:
- Airport IATA/ICAO codes
- Currency fractional units
- Roman numeral conversion
- SI units and quantities
- Animal collective nouns
- Books [data_book]

Dataset Design Goals:
- deterministic factual supervision
- short-form answers
- symbolic precision
- hallucination-sensitive domains
- controlled QA generation
